# Tara — AI Recruitment Coworker

Product case study + interactive prototype for the Tara Recruitment Coworker project.

## Quick start

```bash
cd prototype
npm install
npm run dev
```

- Case study: [http://localhost:5173/](http://localhost:5173/)
- Prototype: [http://localhost:5173/prototype](http://localhost:5173/prototype)

Prototype variants (keys `1`–`3`):

| # | Variant | Axis | When it wins | Cost |
| --- | --- | --- | --- | --- |
| 1 | Quiet Desk | Density & restraint | Daily-use tool that should stay out of the way | Least memorable |
| 2 | Standup Board | Narrative personality | Coworker mental model / end-of-day briefing | Uses more vertical space |
| 3 | Command Surface | Interaction model (glass + sheet) | Fluid review with interruptible gestures | Heavier visuals; needs restraint on data density |
